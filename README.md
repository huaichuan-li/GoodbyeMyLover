# 再见？爱人！ · 3D 医院辨认 Demo

末日感染后，你变成了人马，爱人变成了木乃伊。你们在停电的医院走散，必须穿过三层楼找到彼此；而感染让人马眼里的活物全是木乃伊，让木乃伊眼里的活物全是人马。本期聚焦一台笔记本上的双人分屏探索，手电筒照亮有限范围，其余空间沉在黑暗中。实现暂不包含真机网络与多主机部署。

## 启动

使用静态 HTTP 服务打开游戏（从 `file://` 双击打开时浏览器会阻止 GLB 贴图加载）：

```sh
python3 -m http.server 8081
```

然后在 Chrome 或 Edge 打开 `http://127.0.0.1:8081/index.html`。如果已经运行项目服务，也可打开 `http://127.0.0.1:8080/index.html`。Three.js 与 GLTFLoader 随项目本地提供，不依赖 CDN。医院包含三层程序化楼层、中央楼梯以及病床、推车、手电筒和感染者模型。可玩区域的墙体直接使用移动碰撞布局生成，保证门洞、墙面和镜头遮挡一致；完整医院 GLB 保留在资产预览台中，待与逻辑布局对齐后再接入。环境保持昏暗，每位玩家的视野由人物眼前的独立手电光束照亮。

## 操作

| 玩家 | 操作 |
|---|---|
| A | `W A S D` 移动；第一人称点击左半屏捕获鼠标后直接移动转视角（`Esc` 释放），第三人称拖动鼠标环视；`V` 切换第一/第三人称；`E` 调查/拾取；`F` 辨认；左 Shift 冲刺；`R` 紧急同步；`X` 放弃 |
| B | 外置 Xbox 类手柄左摇杆移动、右摇杆转视角；`Y` 切换第一/第三人称；`A` 调查/拾取；`X` 辨认；`B` 冲刺；`LB` 紧急同步；`RB` 放弃 |
| 系统 | 标题页任意键查看背景及操作；`2` 快速开始双人游戏；说明页手柄 `A` / `Menu` 开始；`Esc` 返回标题；`M` 静音 |

靠近楼梯后按调查键切换楼层。两张地图、外貌线索、手机收件箱和临时提示各自留在玩家半屏。地图只显示探索区域。拾取手机后，进入其他科室会自动向对方发送房间短信。当前版本的手电照明随视角转动；蜡烛点亮互动、手电电池和更完整的搜寻玩法留待后续实现。

第三人称镜头遇墙和静态道具时会向人物回缩，贴近人物后隐藏自身模型；镜头高度受到楼层墙高限制。人物眼睛到目标的视线被墙阻挡时，目标不会显示或成为交互对象，防止通过第三人称绕墙辨认。第一人称采用 FPS 式鼠标自由视角：点击左屏后捕获鼠标，直接移动鼠标即可转向，按 `Esc` 释放；第三人称仍使用拖动环视。鼠标只控制左屏，右屏仅接受手柄；手柄需在游戏页面激活后按一下按钮以便浏览器识别。

## 回归验证

使用 Node.js 运行 `node tools/verify-controls.mjs`，无需安装额外依赖。检查直接执行生产代码，并使用本地 Three.js 的相机、射线和包围盒计算，覆盖六组出生点 WASD、双人输入隔离、手柄映射、30/60/120 FPS 转速一致性、门洞通行、三层楼墙角镜头及近裁剪面、墙后目标遮挡、独立手电、场景重建和 GLB 尺寸归一化。测试以 CPU 渲染接收器代替 WebGL，不能代替实际画面或实体手柄测试。

## 辨认循环

双方随机出生在不同楼层。桌面物品提供对方的外貌特征；医院 NPC 每局随机获得站立、行走、慢跑、躺地或游走状态。靠近 NPC 并按辨认键，认错只降低当前玩家生命值，不改变线索。找到对方后，双方都需各自确认，才进入相认结局。另有认错与放弃结局；没有感染度、倒计时或火箭逃亡流程。

## 角色与场景资产接口

角色目前仍由程序化方块表示，方便后续替换为组员设计的人物模型。逻辑身份和位置仍保存在 `G.Game.world` 实体上，模型只负责渲染。医院模型替换也需保留楼层、碰撞边界、楼梯连接点和科室标识。当前场景资产来源和 CC BY 署名见 [`assets/publics/model/sketchfab/ATTRIBUTION.md`](assets/publics/model/sketchfab/ATTRIBUTION.md)；模型尺寸会在加载时自动归一化。直接通过 `file://` 打开时 GLB 会退回程序化占位物，HTTP 服务模式才能显示模型。
