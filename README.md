# 再见？爱人！ · 3D 医院辨认 Demo

本期聚焦一台笔记本上的双人分屏互相辨认。两个 viewport 分别跟随 A、B，当前楼层不同的角色互不可见；同屏测试时可用纸板遮住屏幕中线。实现暂不包含真机网络与多主机部署。

## 启动

使用静态 HTTP 服务打开游戏（从 `file://` 双击打开时浏览器会阻止 GLB 贴图加载）：

```sh
python3 -m http.server 8081
```

然后在 Chrome 打开 `http://127.0.0.1:8081/index.html`。如果已经运行项目服务，也可打开 `http://127.0.0.1:8080/index.html`。Three.js 与 GLTFLoader 随项目本地提供，不依赖 CDN。没有替换医院楼层结构；已接入的素材用于病房道具：病床、医用推车、拾取手机和体力罐头。其余走廊/病房 GLB 保留为后续关卡参考，当前继续使用程序化医院结构：一楼挂号大厅与药房，二、三楼各五个科室，楼梯位于中央平台。

## 操作

| 玩家 | 操作 |
|---|---|
| A | `W A S D` 移动；`E` 调查/拾取；`F` 辨认；左 Shift 冲刺；`X` 放弃 |
| B | 方向键移动；`;` 调查/拾取；`,` 辨认；右 Shift 冲刺；`]` 放弃 |
| 系统 | `2` 开始双人游戏；`Esc` 返回标题；`M` 静音 |

靠近楼梯后按调查键切换楼层。两张地图、外貌线索、手机收件箱和临时提示各自留在玩家半屏。地图只显示探索区域。拾取手机后，进入其他科室会自动向对方发送房间短信。蜡烛常亮，手机本期不耗电；冲刺消耗体力，体力会恢复。

## 辨认循环

双方随机出生在不同楼层。桌面物品提供对方的外貌特征；医院 NPC 每局随机获得站立、行走、慢跑、躺地或游走状态。靠近 NPC 并按辨认键，认错只降低当前玩家生命值，不改变线索。找到对方后，双方都需各自确认，才进入相认结局。另有认错与放弃结局；没有感染度、倒计时或火箭逃亡流程。

## 角色与场景资产接口

角色目前仍由程序化方块表示，方便后续替换为组员设计的人物模型。逻辑身份和位置仍保存在 `G.Game.world` 实体上，模型只负责渲染。医院模型替换也需保留楼层、碰撞边界、楼梯连接点和科室标识。当前场景资产来源和 CC BY 署名见 [`assets/publics/model/sketchfab/ATTRIBUTION.md`](assets/publics/model/sketchfab/ATTRIBUTION.md)；模型尺寸会在加载时自动归一化。直接通过 `file://` 打开时 GLB 会退回程序化占位物，HTTP 服务模式才能显示模型。
