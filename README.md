# 眼中皆是你 · 网页游戏 demo

抽签主题：**恐怖 / 即时动作 / 马**　｜　方案 A：分屏感知错位 + 相认机制
末日丧尸爆发，主角感染变成人马，爱人感染变成木乃伊。感染改写的是**视觉认知**：人马眼中一切活物都是木乃伊，木乃伊眼中一切活物都是人马。满城都是"爱人"，你们认不出彼此。

---

## 运行（三种方式，零依赖）

| 方式 | 操作 |
|---|---|
| 直接双击 | 打开 `index.html`（`file://` 可跑） |
| 本地服务（推荐自检） | `node tools/serve.mjs` → `http://127.0.0.1:8080/` |
| 断网 / 无 Node 路演 | 双击 `standalone.html`（全部 css/js 已内联） |

不需要 `npm install`，没有构建链、没有 CDN 请求、没有外部素材。Node 仅用于可选的本地服务与打包脚本。
`standalone.html` 由 `node tools/build-standalone.mjs` 生成；改过 css/js 后需重新生成一次。

## 键位

| | 键 |
|---|---|
| A · 人马 | `W A S D` 移动 · `左 Shift` 冲刺撞踏 · `Q` 切换候选 · `F` 报数 · `空格` 敲暗号 · `R` 看倒影 |
| B · 木乃伊 | `方向键` 移动 · `右 Shift` 冲刺 · `E` 切换候选 · `Enter` 报数 / 敲暗号 |
| 单机 | `Tab` 接管切换 · `V` 双屏观察 · `1 / 2 / 3` 结局抉择 |
| 调试 / 展示 | `M` 静音 · `H` 显真形 · `T` 快进到相认 · `Y` 快进到抉择 · `P` 展演亮度 · `Esc` 回到标题 |

> `T` / `Y` 是展演快进键：路演时不必等满 5 分钟，可直接跳到相认机制或结局抉择讲解。正常游玩请不使用。

标题页按任意键 → 剧情/键位页 → 按 `1` 单机（AI 同伴）或 `2` 双人同屏。

## 一关流程（3–5 分钟，探索 → 相认 → 逃亡）

1. **探索**：末日医院 A 区找血清；身后一直有蹄声；感染度不可逆上涨，越深越**不能后退**。
2. **相认①·分屏坐标锁定**：屏幕出现 5 个"她"。两侧看到的「在动的人」集合不同、顺序相反。各自报出「我这边第几个在动」，只有指向**同一个实体**才算数。单机时 AI 同伴用字幕报它那一侧的序号。
3. **相认②·节奏暗号**：敲出「三短一长」。假象会慢半拍回声模仿，跟着回声按两次即被带偏 → 认错（感染 +12 / 人性 −15，并多一个"长成她样子"的跟随者）。
4. **相认③·倒影 + 行为测试**：走到水洼边按 `R`，倒影显示真形；丧尸扑来时只有真爱人会挡在你前面。
5. **逃亡**：往右冲向发射通道，冲刺撞踏开路，感染加速。
6. **抉择**：舱门只开一次，血清给谁 → 6 类结局。

> 演示建议：**默认走单机路径**（一台电脑一个键盘，AI 同伴会报信息）；双人同屏作为加分演示。按 `V` 可在单机下临时打开双屏观察模式讲解「两屏看到的不一样」。

## 目录

```
index.html          单页入口（按序引入经典 script，不用 ESM，兼容 file://）
css/style.css       暗色基底 / 分屏 HUD / 字幕 / QTE 节奏条 / 结算卡
data/config.js      全部数值、键位常量、暗号谱、时间轴
data/script.js      剧情、拟声字幕、HUD 撒谎文案、结局文案
js/core.js          命名空间 / 事件总线 / 状态机 / 固定步长循环 / 总控
js/world.js         实体工厂 / 唯一 world / perception.project 感知投影
js/input.js         键位表 / 带时间戳的输入缓冲环
js/render.js        程序化剪影 / 雾与视野锥 / 单 canvas 双 viewport / 水坑倒影
js/audio.js         Web Audio 合成器 / 手势解锁 / 突然静音硬切
js/systems.js       移动与不能后退 / 感染数值 / 字幕 / 恐怖调度 / AI 同伴
js/recognition.js   坐标锁定 / 节奏 QTE 回声干扰 / 倒影验证 / 认错代价
js/levels.js        三区关卡布局 / 时间轴保底推进
js/ui.js            HUD / 字幕 / QTE 节奏条 / 标题·剧情·抉择·结局卡
js/boot.js          启动入口（必须最后加载）
tools/serve.mjs     零依赖本地静态服务
tools/build-standalone.mjs  单文件打包
设计文档.md         完整创意发散、四方案对比、机制与数值、验收与风险
standalone.html     内联单文件（生成物）
```

> 实现说明：为控制 `file://` 下的 script 数量，把同层细碎模块做了合并（`core.js` 合并 loop+state-machine，`render.js` 合并剪影+光照，`systems.js` 合并 movement/infection/subtitles/horror/ai）。职责边界与计划一致，没有引入任何依赖。

## 验收清单（自检用）

- [ ] `file://` 双击 与 `http://127.0.0.1:8080` 两种方式都能跑，控制台无报错
- [ ] 双人模式左右两屏共享同一坐标/碰撞/感染，但剪影不同（左满眼木乃伊 / 右满眼人马）
- [ ] 单机默认单屏，`V` 可切双屏观察；AI 跟随不卡墙、会报序号、会替挡
- [ ] 感染 > 60 时反向键被吞；冲刺撞踏可开路；感染不可逆
- [ ] 节奏 QTE 在掉帧下仍按时间戳精确判定；假象回声可被跟错
- [ ] 突然静音是瞬时硬切、1.5–2s 硬恢复，期间只留 `[……]` 字幕
- [ ] 4 类以上结局可复现；`H` 显真形 / `P` 展演亮度可用
- [ ] Chrome / Edge / Safari 最新版；16:9 与 4:3 不溢出，resize 不崩

## 风险与规避

| 风险 | 规避 |
|---|---|
| ESM / fetch JSON 在 `file://` 被 CORS 拦 | 全程经典 script + `window.G`；数据放 `.js`；`standalone.html` 兜底 |
| 双屏两套渲染掉帧 | 静态层用 pattern 平铺；雾用渐变矩形；逻辑固定步长与渲染解耦 |
| Web Audio 自动播放被拦 | 标题页按键手势解锁；后台标签页 suspend/resume |
| 同屏双人物理上能互看 | 各自按键报数、序号只在本侧显示；路演默认单机 |
| 观众看不懂相认机制 | 开场键位卡 + 拟声字幕 + 节奏条 + AI 报信息 + A/B 角标 |
| 静音太久被当成卡死 | 严格 ≤2s，期间保留 `[……]` 与极轻视觉脉冲 |
| 恐怖过度 | 不用 jump scare、不用 BGM 拉满；靠突然静音 + 剪影 + 字幕 |
