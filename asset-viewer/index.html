使用说明

启动

在项目根目录执行 node tools/serve-assets.mjs，浏览器打开 http://127.0.0.1:8081/asset-viewer/index.html。服务只监听本机，three.js 已放在 asset-viewer/vendor/，断网也能用。

新增资产

把新 .glb/.gltf 放进 assets/publics/model/、新图片放进 assets/，点左侧「刷新」即可出现。模型若在 manifest.json 登记过作者/许可/面数，会自动带出元数据；未登记的会标注「未核验许可」。

3D 操作

左键拖动旋转、滚轮缩放、右键拖动平移；工具条可切正/背/左/右/顶/等距视角、自动旋转、线框、地面网格、重置、保存截图、全屏。模型会自动居中并按尺寸归一化，不同比例的模型都能看清。

团队挑选

每个资产可标记 选用 / 待定 / 不用、加星标、写备注，自动保存在本机。用「导出清单」生成 Markdown 贴到 GitHub 或群聊；用「JSON 导出 / 导入」在组员之间同步挑选结果。

许可提醒

Sketchfab 这批模型全部为 CC BY，只要还在场景里就必须保留「模型名 + 作者 + 来源链接 + 许可」。完整署名表见 assets/publics/model/sketchfab/ATTRIBUTION.md。概念图原图带 AI 生成标识，对外发布请使用原图或补齐标识。

这些是策划侧占位资产；人物设计与正式资产由其他组交付后，保持文件名不变替换即可。
