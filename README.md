# 再见？爱人！ · 3D 医院辨认 Demo

本期聚焦一台笔记本上的双人分屏互相辨认。两个 viewport 分别跟随 A、B，当前楼层不同的角色互不可见；同屏测试时可用纸板遮住屏幕中线。实现暂不包含真机网络与多主机部署。

## 启动

使用静态 HTTP 服务打开 `index.html`。项目没有 3D 引擎或 CDN 依赖。仓库中没有医院场景原文件，因此使用程序化占位场景：一楼挂号大厅与药房，二、三楼各五个科室，楼梯位于中央平台。

## 操作

| 玩家 | 操作 |
|---|---|
| A | `W A S D` 移动；`E` 调查/拾取；`F` 辨认；左 Shift 冲刺；`X` 放弃 |
| B | 方向键移动；`;` 调查/拾取；`,` 辨认；右 Shift 冲刺；`]` 放弃 |
| 系统 | `2` 开始双人游戏；`Esc` 返回标题；`M` 静音 |

靠近楼梯后按调查键切换楼层。两张地图、外貌线索、手机收件箱和临时提示各自留在玩家半屏。地图只显示探索区域。拾取手机后，进入其他科室会自动向对方发送房间短信。蜡烛常亮，手机本期不耗电；冲刺消耗体力，体力会恢复。

## 辨认循环

双方随机出生在不同楼层。桌面物品提供对方的外貌特征；医院 NPC 每局随机获得站立、行走、慢跑、躺地或游走状态。靠近 NPC 并按辨认键，认错只降低当前玩家生命值，不改变线索。找到对方后，双方都需各自确认，才进入相认结局。另有认错与放弃结局；没有感染度、倒计时或火箭逃亡流程。

## 角色与场景资产接口

角色目前由 `js/render.js` 中 `room()` 的 `player` 分支绘制为程序化方块。后续可替换为 `.glb`（glTF 2.0 binary）模型：米制尺寸、朝向 +Z、脚底原点、建议身高 1.7–2.0 米。逻辑身份和位置仍保存在 `G.Game.world` 实体上，资产只负责渲染。医院模型替换也需保留楼层、碰撞边界、楼梯连接点和科室标识。当前不引入外部模型，以保持零依赖和 `file://` 兼容方向。

## 后续扩展

短信面板、电池/GPS、多主机同步，以及医院逃脱和火箭离地球等环境副任务留待后续版本；本期不实现。
