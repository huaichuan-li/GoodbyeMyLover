# 再见？爱人！ · 3D 医院辨认 Demo

末日感染后，所有人眼里的活物都被扭曲成同一种模样：你眼中的人是木乃伊，对方眼中的人也是木乃伊。两名玩家在停电的医院一楼走散，只能靠外貌线索、手电和紧急同步在走廊里相互辨认。本期是一台笔记本上的同屏双人探索切片：左半屏键盘 + 鼠标操控 A，右半屏手柄操控 B；不含真机网络与多主机部署。

> 版本：**v1.3-assets**（单层医院 + 真实 GLB 场景与骨骼动画角色）。概念立绘版见 `v1.1-art`，最初 Canvas 版见 `v1.0-demo`，均可回退。

## 启动

完整版必须经静态 HTTP 服务打开（`file://` 双击时浏览器会拦截 ES module 与 GLB 贴图）：

```sh
node tools/serve.mjs 8080
# 或 python3 -m http.server 8080
```

然后打开 `http://127.0.0.1:8080/index.html`。Three.js、GLTFLoader 与 SkeletonUtils 均随项目本地提供，不依赖 CDN。加载遮罩会在模型就绪或 3 秒超时后淡出。

`standalone.html` 是早期 Canvas 2D 单文件版的断网路演保险，**不加载 GLB**；本轮单层 3D 改造未同步到它。用 `file://` 直接打开 `index.html` 时也会走程序化回退（无 GLB 场景/动画角色）。

## 场景与资产

游戏现在是**单层一楼医院**（1F）：挂号大厅、药房、急诊分诊、一楼候诊四个科室区，中央走廊贯通，三处污染危险区。旧的四层布局、楼梯切换与楼层 UI 已移除。

| 资产 | 路径 | 用途 |
|---|---|---|
| 医院场景 | `assets/publics/model/hospital_1f.glb` | 家具、器械、氛围装饰（1.4 MB） |
| 木乃伊角色 | `assets/animated/mummy_animated.glb` | 全员共用基础体型 + `Idle/Walk/Limp_Right` 三段动画（16 MB，22 骨骼） |
| 道具 | `assets/publics/model/sketchfab/*.glb` | 病床、推车、手机、食物、电池、输液架、手电 |

关键约定：

- 医院 GLB 中 `WALL_` 前缀的结构件在运行时隐藏，**墙矩形仍以 `w.walls` 为唯一真源**，保证碰撞、遮挡、镜头避障与手电判定一致；场景装饰 mesh 禁用 raycast。
- 角色 GLB 用 `SkeletonUtils.clone` 共享几何/材质/贴图，只克隆骨骼层级；7 种外貌 trait 作为小挂件挂到骨骼上，`limpGait`（跛行）直接播放 `Limp_Right` 动画，无挂件。
- 灯灭环境下两名玩家各持一盏独立手电，只照亮自己半屏；第三人称镜头遇墙/家具自动回缩。

转换医院 `.blend` 到 GLB 的工具见 `tools/inspect-hospital-blend.py`、`tools/export-hospital-glb.py`，检查结果见 `tools/ASSET_INSPECT.md`。角色预览见 `assets/animated/preview.html`。

## 操作

| 玩家 | 操作 |
|---|---|
| A | `W A S D` 移动；第一人称点击左半屏捕获鼠标后直接移动转视角（`Esc` 释放），第三人称拖动鼠标环视；`V` 切换第一/第三人称；`E` 调查/拾取；`F` 辨认（队友在 3 米内时直接发起/回应相认，也可用 `Y`/`N` 或手柄键做照射确认）；左 Shift 冲刺；`R` 紧急同步；`X` 放弃；调试模式 `L` 切明亮 |
| B | 外置 Xbox 类手柄左摇杆移动、右摇杆转视角；`Y` 切换第一/第三人称；`A` 调查/拾取；`X` 辨认；`B` 冲刺；`LB` 紧急同步；`RB` 放弃 |
| 系统 | 标题页任意键查看背景及操作；`2` 快速开始双人游戏；说明页手柄 `A` / `Menu` 开始；`Esc` 返回标题；`M` 静音 |

两张地图、外貌线索、手机收件箱和临时提示各自留在玩家半屏，地图只显示探索区域。拾取手机后进入其他科室会自动向对方发送房间短信。手电照射会冻结对方，被照方需用自己的确认键（键盘 `Y`/`N` 或手柄方向键）判定，`F`/`X` 在冻结期间无效。

## 回归验证

```sh
node tools/verify-controls.mjs        # 37 组回归，无需安装依赖
node tools/verify-browser.mjs         # 可选：无头 Chrome CDP 验证（需 Node 22 + 调试端口 9222）
```

`verify-controls.mjs` 直接执行生产代码，用本地 Three.js 的相机/射线/包围盒计算，覆盖六组出生点 WASD、双人输入隔离、手柄映射、30/60/120 FPS 转速一致性、门洞通行、单层墙角镜头与近裁剪面、墙后遮挡、独立手电、场景重建、GLB 尺寸归一化，以及本轮新增的单层数据断言、医院 GLB 结构件隐藏、骨骼动画 mixer/trait 挂件、`limpGait` 动作映射。CPU 渲染接收器代替 WebGL，不替代真实画面/实体手柄测试。

`verify-browser.mjs` 用 CDP 检查 GLB 是否全部 HTTP 200、有无控制台/异常错误、游戏能否进入 PLAY、世界是否单层；需先启动带 `--remote-debugging-port=9222` 的 Chrome。

## 辨认循环

双方从一楼两端出生，路线中间穿过危险区。桌面线索卡分别揭示对方的两条外貌特征（蓝色腕带 + 跛行 / 深色外套 + 银色徽章）。8 名木乃伊 NPC 每局随机获得站立、行走、慢跑、躺地或游走状态与随机 trait。靠近 NPC 按调查键可观察外貌、按辨认键可比对（认错扣共享血量并生成镜像怪）。队友进入 3 米内按辨认键即可发起相认，双方都按后进入逃生阶段，双双抵达一楼走廊尽头的出口才算逃生成功。共享血量归零会倒地，队友靠近长按可救援。另有认错与放弃结局；不含感染度倒计时或火箭流程。
